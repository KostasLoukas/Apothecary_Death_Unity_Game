# Apothecary Death - A Unity Game

Apothecary Death is a short horror game experience about a man that found himself waking up in an abandoned establishment. His goal? Get out and be quick; who knows what dangers lurk in the shadows of that bunker...

Inspired by the popular saga of the "Dungeon Nightmares" games, it brings a new, fresh (and amateur) perspective to the dungeon crawler genre!

This game is a full release of the original idea and was created for an exercise in the context of one of my master's exams. The game is not to be taken seriously; it is merely for entertainment purposes only.

You can find the fully playable game on itch.io here: https://kostasloukas.itch.io/apothecary-death
